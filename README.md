# HACK-2: Maquetación con Float

## Descripción
Este proyecto corresponde al segundo hack del diplomado.  
Se replicó la misma interfaz de línea de tiempo del HACK-1, pero utilizando exclusivamente **`float`** para la maquetación, con los rectángulos alineados a la izquierda.

## Tecnologías usadas
- HTML5
- CSS3 (Float)
- Git + Conventional Commits

## Restricciones cumplidas
- ✅ Uso exclusivo de `float`
- ❌ Sin `position` (prohibido)
- ❌ Sin `flex` (prohibido)
- ✅ Rectángulos 1 y 2: centrados
- ✅ Rectángulos 3, 4, 5, 6: alineados a la izquierda con `float: left`
- ✅ Rectángulo 7: centrado con `clear: both`
